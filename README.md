# Warehouse Material Monitoring System (OFFLINE READY)

Sistem monitoring material warehouse yang modern, responsif, dan bisa berjalan 100% tanpa internet.

## Fitur
- **Dashboard**: Statistik stok total, item hampir habis (low stock), dan aktivitas terbaru.
- **Inventory**: Manajemen data material (ID, Nama, Kategori, Satuan).
- **Transactions**: Pencatatan Material Masuk (In) dan Material Keluar (Out).
- **History**: Riwayat transaksi yang dapat difilter.
- **Data Persistence**: Data disimpan secara lokal di browser (LocalStorage).

## Cara Penggunaan
1. Buka file `index.html` menggunakan browser (Chrome, Edge, Firefox).
2. Gunakan tombol **"Material In"** untuk menambah stok.
3. Gunakan tombol **"Material Out"** untuk mencatat pengambilan barang.
4. Kelola daftar material di menu **"Inventory"**.
